## The Edge Worker — the headline primitive

Five jobs, one Worker, no origin code required.

### 1. Observe
Every request is classified via `@nuxtjs/robots`'s `AI_BOTS` pattern set (GPTBot, ClaudeBot, anthropic, Google-Extended, Applebot-Extended, PerplexityBot, Bytespider, CCBot, cohere, diffbot, googlebot-news). On match, we log `{ts, ua, engine, path, status, country, cf-ray}` to D1 with a hot-window TTL and stream to R2 Parquet for retention. Non-AI UAs pass through untouched.

### 2. Inject
On HTML responses we run `HTMLRewriter`:
- Insert `<link rel="alternate" type="text/markdown" href="…">` when a markdown alternative exists.
- Insert JSON-LD scaffolding (Article, Breadcrumb, Organization) where origin omitted it.
- Surface our generated `llms.txt` at `/llms.txt` and `/llms-full.txt`.
- Insert sitemap if origin lacks one.

### 3. Pre-render
If the request is from a non-JS crawler and the origin returns an empty `<body>` (SPA), we render server-side via a paired Browser Rendering Worker, cache the result in R2 keyed by `url + content-hash`, serve from cache on subsequent hits.

### 4. Submit
New paths (first-seen URLs returning 200) enqueue a submit job to Cloudflare Queues. Workers consume the queue and fire Indexing API + IndexNow + sitemap pings, respecting per-engine quotas. Failures retry with backoff; permanent failures surface to the dashboard.

### 5. Serve markdown
Requests with `Accept: text/markdown` or `?format=md` receive a server-rendered Markdown projection of the page (lifted via Mozilla Readability + Turndown). Bypasses the SPA prerender entirely.

## Data model (Drizzle on D1 + Parquet on R2)

```
sites              one row per CNAME'd domain
  ├─ origin_host
  ├─ verification_token
  ├─ tier (free/pro/scale)
  └─ retention_days

crawler_hits       hot 30 days in D1, archived to R2 Parquet
  ├─ site_id, ts, engine, path, status, country, ua_hash

indexing_jobs      Cloudflare Queue mirror + final state
  ├─ site_id, path, transport (google|bing|yandex|...), state, attempts, last_error

citation_runs      one per (site, prompt, llm, day)
  ├─ site_id, prompt_id, model, ts, cited (bool), position, snippet, sources[]

llmstxt_versions   diffable history
  ├─ site_id, ts, content_hash, generated_from (auto|manual)

gsc_history        append-only Parquet partitioned by site/date
  └─ via @gscdump/engine — never deleted
```

## MCP surface

Above `@gscdump/mcp`'s GSC tools, add:

- `index.submit(site, paths[])` → fires Indexing API + IndexNow
- `index.status(site, paths[])` → indexed/discovered/crawled/error
- `citations.track(site, prompts[], models[])` → schedules + returns latest
- `citations.history(site, query, window)` → time-series of citation share
- `crawlers.recent(site, engine?, since?)` → AI crawler hits at edge
- `llmstxt.generate(site)` → produce + return current `llms.txt`
- `llmstxt.diff(site, from, to)` → diff between two versions
- `prerender.invalidate(site, paths[])` → bust prerender cache

Each tool returns a typed `Result<T>` from `@gscdump/contracts`. No raw JSON dumps.

1. **Engine wiring** — pull in the `@gscdump/*` v1 packages and wire `engine-sqlite` to existing D1.
2. **Steal from nuxtseo.com** — pro-indexing, pro-gsc, pro-chat, pro-saas-auth, pro-saas-billing. Resolve duplicates with our existing `layers/pro-saas-*`.
